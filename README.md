## Описание плагина
**Timestamp Helper** — это простое, но полезное расширение для редактора Visual Studio Code, разработанное в рамках лабораторной работы. Плагин позволяет мгновенно вставлять текущую актуальную дату и время в текущую позицию текстового курсора в документе с помощью удобной палитры команд.

## Возможности и функционал
* **Быстрая вставка:** Добавление текущей локализованной даты и времени (в формате `ДД.ММ.ГГГГ, ЧЧ:ММ:СС`) в позицию курсора.
* **Уведомления:** Вывод всплывающего информационного сообщения (`showInformationMessage`) при успешной вставке метки времени.
* **Проверка редактора:** Автоматическая проверка открытого текстового документа (если активный редактор отсутствует, плагин выведет предупреждение).
* **Интеграция с Command Palette:** Доступ к функционалу через стандартную палитру команд VS Code.

## Как использовать
1. Откройте любой текстовый файл в VS Code.
2. Нажмите комбинацию клавиш `Cmd + Shift + P` (на macOS) или `Ctrl + Shift + P` (на Windows/Linux), чтобы открыть палитру команд.
3. Введите и выберите команду: **`Вставить текущую дату и время`** (`timestamp-helper.insertTimestamp`).
4. Текущая дата и время мгновенно появятся в месте нахождения курсора.
